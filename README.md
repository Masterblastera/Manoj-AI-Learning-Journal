# Python Notes

## Python Setup Troubleshooting

Temporary PATH Fix:

```bash
export PATH="/c/Users/user/AppData/Local/Programs/Python/Python315:$PATH"
```

Permanent PATH Fix:

```bash
echo 'export PATH="/c/Users/user/AppData/Local/Programs/Python/Python315:$PATH"' >> ~/.bashrc
```

Reload:

```bash
source ~/.bashrc
```

Verify:

```bash
python --version
```
